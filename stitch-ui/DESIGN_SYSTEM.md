## Brand & Style

This design system establishes an authoritative, high-efficiency operational environment for enterprise workforce monitoring, shift orchestration, and compliance auditing. Combining executive prestige with mission-critical clarity, the aesthetic blends structured Corporate Modern discipline with subtle Luxury Precision accents.

### Personality & Values
- **Command & Certainty:** Interfaces eliminate ambiguity. Time records, attendance states, and audit trails are presented with definitive visual weight.
- **Dignified Prestige:** Grounded by deep imperial crimson and refined radiant gold accents, elevating standard punch-clock utilities into an executive-tier command console.
- **Senior & Accessible Usability:** High-contrast color assignments, generous interactive targets, and clear structural division ensure effortless operation for floor supervisors, enterprise HR directors, and on-the-move shift staff alike.

### Visual Language
The interface utilizes an elevated crisp porcelain canvas bounded by razor-thin slate borders, calibrated tonal layer elevations, and localized micro-glows in crimson and gold to denote priority states, geofence validations, and active shifts.

## Colors

The palette balances authoritative deep crimson against crisp porcelain planes and radiant warm gold metrics, backed by functional semantic signals for instantaneous real-time monitoring.

### Core Swatches
- **Primary (Imperial Crimson):** `#991B1B` (Base interactive primary), `#7F1D1D` (Hover / Active state), `#B91C1C` (High-visibility accent / Alerts).
- **Secondary (Radiant Gold):** `#D97706` (Accent metrics, executive badges), `#F59E0B` (Warning, late check-in flag), `#B45309` (Active border / Focus rings), `#FEF3C7` (Soft gold badge fill).
- **Tertiary (Verification Emerald):** `#047857` (On-Duty active state, Geofence verified badge), `#10B981` (Vibrant signal dot), `#ECFDF5` (Verified pill fill).
- **Neutral (Slate Carbon & Porcelain):** 
  - Text & Structural: `#0F172A` (Primary ink), `#334155` (Secondary label ink), `#64748B` (Muted caption ink).
  - Canvas & Panels: `#FFFFFF` (Card surfaces), `#F8FAFC` (Canvas background), `#F1F5F9` (Subtle container / Hover fill), `#E2E8F0` (Default borders).

### Functional Token Mapping
- Surface default: `#F8FAFC`
- Surface container (Cards, App Bar): `#FFFFFF`
- Surface border: `#E2E8F0`
- Critical / Overdue: `#B91C1C` text with `#FEF2F2` background.
- Warning / Late: `#D97706` text with `#FFFBEB` background.
- Validated / On-Duty: `#047857` text with `#ECFDF5` background.

## Typography

Typography prioritizes legibility under high operational pressure. The pairing combines **Plus Jakarta Sans** for structural headers and digital clock readouts with **Inter** for data grids, metadata timestamps, and enterprise controls.

- **Numerics & Clocks:** Punch clocks, live shift counters, and duration meters utilize tabular numerals (`tnum`) to eliminate visual jitter during real-time sync.
- **Labels & Chips:** Badges enforce uppercase or title-case micro-tracking (`letterSpacing: 0.02em` to `0.04em`) to ensure legibility on ruggedized kiosk monitors or high-density supervisor tables.
- **Text Contrast:** All critical body text meets a minimum contrast ratio of 7:1 against card backgrounds, well exceeding WCAG AAA compliance for accessibility.

## Layout & Spacing

The layout follows a deterministic 8px modular cadence governed by strict vertical and horizontal alignment.

### Grid Framework
- **Desktop (>= 1280px):** 12-column responsive fluid grid with 24px (`1.5rem`) gutters and 32px (`2rem`) outer margin. The primary navigation is anchored in a fixed 280px left rail.
- **Tablet (768px – 1279px):** 8-column layout with 20px gutters and 24px margins. Navigation collapses to an icon bar or overlay sheet.
- **Mobile (< 768px):** 4-column layout with 16px (`1rem`) gutters and 16px (`1rem`) outer margins. Critical actions (Check In/Out, Biometric Scan trigger) transition into a persistent bottom sheet or sticky action bar.

### Spacing Philosophy
- Operational modules enforce generous internal padding (`space-lg`) to prevent mis-clicks on touch-enabled kiosk devices.
- Touch target minimums are standardized at `48x48px` for all interactive triggers, buttons, and row expansions.

## Elevation & Depth

Visual hierarchy is maintained through crisp surface layering, selective tinted borders, and soft warm-hued ambient halos that identify active alerts without clutter.

### Elevation Levels
- **Level 0 (Base Canvas):** `#F8FAFC`, flat, 0px elevation. Houses the master dashboard substrate.
- **Level 1 (Operational Cards & Data Rows):** Pure `#FFFFFF` resting surface with a 1px solid border in `#E2E8F0` and an ultra-diffused shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.02)`.
- **Level 2 (Active Shifts & Hover Focus):** Subtle elevation with specialized gold/crimson boundary glows. Shadow: `0 4px 6px -1px rgba(15, 23, 42, 0.06), 0 2px 4px -2px rgba(15, 23, 42, 0.04)`.
- **Level 3 (Modals, Biometric Dialogs, Flyouts):** High-priority focus layer. Shadow: `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.05)`.

### Accent Glow Signatures
- **Geofence Active / Verified:** `box-shadow: 0 0 0 1px rgba(16, 185, 129, 0.3), 0 0 16px -2px rgba(16, 185, 129, 0.15)`.
- **Late Alert / Priority Action:** `box-shadow: 0 0 0 1px rgba(217, 119, 6, 0.35), 0 0 16px -2px rgba(245, 158, 11, 0.2)`.
- **Audit / Emergency Punch Overdrive:** `box-shadow: 0 0 0 1px rgba(153, 27, 27, 0.35), 0 0 20px -2px rgba(185, 28, 28, 0.25)`.

## Shapes

The design system embraces a **Soft (Level 1)** structural curvature. This provides an engineered, technical precision that matches high-density enterprise software without the brutal edge of zero-radius corners.

- **Base Corner Radius (Inputs, Chips, Buttons):** `4px` (`0.25rem`).
- **Surface & Panel Containers (Cards, Modals):** `8px` (`0.5rem`).
- **Compound Sections (Outer App Shell Containers):** `12px` (`0.75rem`).
- **Indicators & Verification Avatars:** Pure circles (`9999px`) to immediately contrast against angular structural frames.

## Components

### Buttons
- **Primary Action (Record Check-In, Confirm Biometrics):** Background `#991B1B`, text `#FFFFFF`, border none, height 48px, horizontal padding 24px. Hover state shifts to `#7F1D1D` with subtle crimson micro-glow.
- **Secondary (Export Audit, Filter Logs):** Background `#FFFFFF`, text `#0F172A`, 1px solid `#E2E8F0`. Hover state shifts to background `#F8FAFC` and border `#CBD5E1`.
- **Accent (Manual Override / Verify):** Background `#FEF3C7`, text `#B45309`, 1px solid `#FDE68A`. Hover brings `#FDE68A`.

### Status Chips & Badges
- **On-Duty:** Background `#ECFDF5`, text `#047857`, 1px border `#A7F3D0`. Includes a 6px pulsating `#10B981` radial dot.
- **Late / Flagged:** Background `#FFFBEB`, text `#B45309`, 1px border `#FDE68A`.
- **Geofence Verified:** High-prestige badge with 1px border `#D97706`, background `#FFFFFF`, text `#92400E`, prepended by a micro gold shield icon.
- **Absent / Critical Breach:** Background `#FEF2F2`, text `#991B1B`, 1px border `#FECACA`.

### Cards & Data Panels
- Metric cards feature a 4px top accent line colored dynamically by card role (Imperial Crimson for anomalies/penalties, Warm Gold for total hours/headcount, Emerald for on-site headcount).
- Surfaces are crisp `#FFFFFF` bounded by 1px `#E2E8F0` outlines, maintaining a clean visual rhythm across 3-up and 4-up metric grids.

### Input Fields & Search Bars
- Standard height: 44px. Background `#FFFFFF`, border 1px solid `#CBD5E1`, text `#0F172A`.
- Focus state: Border color transitions to `#991B1B`, accompanied by a 2px outer outline in `rgba(153, 27, 27, 0.15)`.
- Large kiosk keypad inputs: Minimum touch target 56px with 18px medium typography for field workers entering employee IDs.

### Lists & Audit Tables
- Header cells: `#F8FAFC` background, `#475569` text, `label-sm` typographic styling, uppercase, bottom border 2px solid `#E2E8F0`.
- Data rows: Minimum height 52px. Hover state triggers a subtle porcelain tint (`#F1F5F9`) with transition `0.15s ease`.
- Active user tracking row: Displays an absolute left 3px indicator strip in Radiant Gold or Verification Emerald.

### Checkboxes & Radios
- Square 20x20px container with 3px border radius.
- Default: 1.5px border `#94A3B8`, background `#FFFFFF`.
- Checked: Background `#991B1B`, border `#991B1B`, checked icon rendered in crisp `#FFFFFF`.
